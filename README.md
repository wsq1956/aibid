# AIBID 工作台 · 静态演示版

金宝马 AI 投标与方案助手（AIBID）的界面演示，部署在 GitHub Pages 上，
打开网址即可浏览，无需安装任何东西。

## 这个演示版是什么

界面是**真的**，数据是**跑出来的**，只有后端是没有的。

- 「界面是真的」：`app.js`、`style.css` 与本地运行版**逐字相同**。
  演示版没有为展示另写一套界面 —— 那样演示的就不是真东西了。
- 「数据是跑出来的」：页面上每一个数字 —— 引用偏移、哈希链、自检覆盖率 ——
  都由本地服务端真实执行后导出固化（`demo-data.js`），不是手写编造的。
- 「后端是没有的」：静态页不含服务端逻辑，所以生成结果是**回放**而非实时计算，
  审定按钮会明确拒绝（见下）。

## 数据出处

导出脚本：`scripts/export_static_demo.py`（在完整工程里）。
它直接调用真实的 `Workspace` 类跑一遍流水线，把各接口响应原样写成
`demo-data.js`。别人跑一遍即可复现本页全部内容。

**全部为合成演示数据，不是公司真实资质业绩。**

## 演示版与完整版的差别

| | 静态演示版 | 本地完整版 |
|---|---|---|
| 浏览界面 | ✅ | ✅ |
| 查看研判清单、资质业绩库、审计链 | ✅ 导出的快照 | ✅ 实时读取 |
| 生成标书初稿 | 回放导出结果 | 实时生成并回查 |
| 输入未预置的关键词 | 返回「阻断」，与真实系统 fail-closed 一致 | 实时检索，查不到即阻断 |
| 审定补签四元组 | ❌ 明确拒绝 | ✅ 实时写入审计链 |

最后一条是刻意的：**这个系统的全部价值就在于审计链不可篡改，
演示版更不能自己破例。** 所以静态版宁可报错，也不在前端伪造一条审计记录。

## 运行完整版

完整工程（Python 标准库，无第三方依赖，需 Python 3.11+）：

```
启动AIBID.bat       Windows 双击
启动AIBID.command   macOS 双击
启动AIBID.sh        Linux
```

浏览器会自动打开 `http://127.0.0.1:8765/`。

## 目录

```
index.html      页面骨架（比运行版多一条「静态演示版」说明条）
app.js          前端逻辑，与运行版逐字相同
style.css       样式，与运行版逐字相同
demo-api.js     垫片：把 fetch("/api/…") 接到固化数据上
demo-data.js    导出的演示数据（自动生成，勿手工编辑）
demo-data.json  同上，JSON 格式，便于核对
```
